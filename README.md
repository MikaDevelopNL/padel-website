# Padel Website

Dit is mijn eerste echte webdevelopment-project.

Ik heb deze website gebouwd om mijn basiskennis van HTML en CSS in de praktijk toe te passen en ervaring op te doen met het bouwen van een volledige website.

## 🛠️ Gebruikte technieken

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive design
- Git
- GitHub

## 📚 Wat heb ik geleerd?

Tijdens dit project heb ik geleerd hoe ik een website vanaf de basis kan opbouwen.

Ik heb geoefend met het maken van een duidelijke HTML-structuur, het opbouwen van layouts met Flexbox en Grid en het responsive maken van een website voor verschillende schermformaten.

Daarnaast heb ik voor het eerst ervaring opgedaan met Git en GitHub en geleerd hoe ik mijn project online kan beheren en publiceren.
